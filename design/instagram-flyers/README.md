# Instagram flyers, free estimate offer

Working files for the Parker Construction Company flyer canvas.

- `Main.dc.html` — feed 1080x1350, dark ink
- `FeedLight.dc.html` — feed 1080x1350, stone, centered
- `Story.dc.html` — story 1080x1920, safe zone padding top and bottom
- `canvas.json` — canvas layout
- `parker-free-estimate-flyers.html` — the seeded canvas that gets published

Type: Cormorant Garamond (display) over Jost (labels and body).
Color: ink `#16130F`, stone `#EFEAE2`, brass `#B08D4F`.

Bracketed items are placeholders: phone, website, service area. The
typeset PARKER wordmark stands in for the logo file.
